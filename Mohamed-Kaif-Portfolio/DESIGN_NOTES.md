# Mohamed Kaif — Portfolio

Personal portfolio for Mohamed Kaif S A. Content is based on the saved personal/developer profile dated 21 September 2026, plus the confirmed Chrissoft AI project context. Project descriptions distinguish developed work, prototypes and concepts.

## Design and motion
The reference visual design and motion implementation are by Luke Baffait (https://lukebaffait.fr/). Original third-party license notices are retained. The existing stylesheets, shader renderer, GSAP/ScrollTrigger/Lenis libraries and animation logic are preserved. Only text, links, content data and identity/project image assets have changed.

## Content assets
Nine distinct, editable product-interface previews serve as project thumbnails. They illustrate each project's documented purpose and are labeled “Interface concept / Sample data”; they are not screenshots of running apps or claims of measured results. The SVGs are generated by `scripts/create-project-previews.py`. Project detail diagrams remain separate.

Both About and Info use the portrait selected by the owner on 22 September 2026, copied without edits. Photo framing, styles, motion logic, decorative artwork and the 341-frame scroll sequence are preserved. The earlier editorial cover generation prompts are retained in `docs/artwork-prompts.json` as historical provenance; that artwork is no longer used for covers.

## Structure
Serve `dist` as the root of a static HTTP server. No build is required. Home, Work, Info and Contact each have their own index document. Public profile links are provided by the owner. Unconfirmed project links are omitted. Unreferenced project screenshots and the portrait from the original reference have been removed.
